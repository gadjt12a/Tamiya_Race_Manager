 v9.39  (2026-08-07)  [v10-packaging branch]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  - FIXED: on some PCs the app refused to start and
    threw a stack of error boxes ("Failed to load Tcl
    DLL", "File already exists but should not"). The
    v9.38 splash screen was the cause - it is gone.
  - The app no longer unpacks itself into a temporary
    folder every time it starts. It now installs as a
    normal program folder, so it launches quicker and
    can't be tripped up by leftover temp files or
    anti-virus. Race data is unaffected as always.
  - Portable zip users: unzip the whole folder and run
    TamiyaRaceManager.exe from inside it. The exe needs
    the _internal folder beside it.
  - The app window now opens centred on the screen, sized
    to fit it, instead of drifting down and to the right.
  - Closing a season now warns you properly first: it names
    the season, says how many events it has, and spells out
    what closing does.
  - NEW: closed a season by mistake? "View All Seasons" now
    has a Reopen button that makes it the active season
    again. (Close the current season first - only one can
    be active at a time.)
  - The app now opens roughly 2.5 seconds faster. Every
    launch was wasting about 2 seconds checking whether the
    app was already running, using an address that could
    never answer. There is no splash screen - it starts
    quickly enough now not to need one.
  - Installers and packages are now numbered version.build
    (e.g. 9.39.21). The build number comes from the source
    itself and goes up with every change, so you can always
    tell two downloads apart. It also shows in the app
    header and in the file's Properties.
  - NEW: Full Screen button on the Home and Race screens
    (or press F11 anywhere) - handy for putting the race
    screen up on the big monitor.
  - Home screen tidies up better when you make the window
    narrower: the season buttons wrap instead of being
    squashed off the edge, and the two columns stack
    rather than both being crushed.

SINGLE EXECUTABLE (Phase 3 of v10 plan)
  - The whole app now builds into one file:
    TamiyaRaceManager.exe (~8 MB) - server, app and version
    bundled. No Python download, no python-bundle folder.
    Build with "BUILD EXE (developer use only).bat"
    (requires: python -m pip install pyinstaller).
  - FIXED: on a first run the server could shut itself down
    17-21 seconds after starting if the browser was slow to
    load (antivirus scan, SmartScreen, cold browser start),
    leaving the app showing "server connection lost". The
    shutdown countdown now only starts after the browser has
    connected once (with a 5-minute give-up if none ever
    does).
  - Server now binds to 127.0.0.1 only - private to the
    machine, and avoids the Windows Firewall "Allow access"
    prompt on first run of a new exe.
  - Launching a second copy now just opens the browser to
    the already-running app instead of failing.
  - Port conflict (another program on 8765) now shows a
    friendly message instead of a Python error.
  - Browser opens only after the server is confirmed
    listening.
  - One version source: the VERSION file. Shown in the app
    header (via /info), server console and build script.

DATA RELOCATION & MIGRATIONS (Phase 2 of v10 plan)
  - Race data now lives OUTSIDE the app folder, in
    %LOCALAPPDATA%\TamiyaRaceManager\ (Windows) or
    ~/Library/Application Support/TamiyaRaceManager (Mac),
    so installing or updating the app can never touch it.
    Override with the TAMIYA_DATA_DIR environment variable
    for portable/USB use.
  - First launch COPIES (never moves) existing data and
    backups from the old data\ folder to the new home. The
    old copy is left in place as a backup, with a
    DATA-HAS-MOVED.txt note, and the app shows a one-time
    notice saying where the data now lives.
  - Data files carry a schema version. Opening or importing
    a file made by a NEWER app version is politely refused
    and nothing is written - update the app instead. Old
    files are upgraded automatically, with a tagged
    pre-upgrade backup taken first.

DATA SAFETY (Phase 1 of v10 deployment plan)
  - Automatic daily backups: on the first save of each day
    the server snapshots the data file to data/backups/
    (keeps the last 14 days). Preserves the previous race
    night's final state before anything new is written.
  - Save verification: the app now checks the server
    actually accepted each save. On failure, data is held
    in browser storage and a persistent red banner tells
    the coordinator to Export Data and restart.
  - Lost-server detection: if the server stops responding
    mid-session, a persistent red banner appears instead of
    data silently going nowhere.
  - Sleep-tolerant server: closing the laptop lid no longer
    kills the server when the machine wakes up.
  - Import Data now validates the file, shows a summary
    ("3 seasons, 42 racers") confirmation before replacing
    anything, and keeps a safety copy of the current data.
  - Editing a race result is now crash-safe (the correction
    is saved to the resume snapshot immediately).
  - Season standings are tracked by racer identity rather
    than name, so fixing a name typo mid-season no longer
    splits a racer's points into two rows. Older events
    are matched by name automatically.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
FIXED
  - EVO Junior standings were awarding overall-position points
    instead of junior-rank points. A junior finishing 5th overall
    but 1st among juniors now correctly earns 10 pts in the
    Junior table. Their EVO overall points (6 pts for 5th) are
    unchanged — both tables are independent.

ADDED
  - Crash recovery: active race state is checkpointed to
    DB.activeRace after every confirmed race result. If the app
    or server closes unexpectedly mid-race, restarting shows a
    "Race In Progress — Resume?" modal with the class name,
    racer count, and races completed. Resume restores the bracket
    exactly where it left off. Discard clears the checkpoint.
    Test-mode races are excluded from checkpointing.
  - Atomic file writes: server now writes to racedata.json.tmp
    then renames atomically. The data file can never be left
    half-written or corrupt if the process is killed mid-save.
  - stress-test.py: developer tool that simulates 30 race nights
    (Box + EVO + Pro each night, 8–14 racers per class, 3–5
    juniors in EVO) and validates data integrity. Run with
    "python stress-test.py [runs]". Passed 270 events with 0
    errors across 3 runs.

FIXED
  - 2nd Chance bracket logic: when mainPool===1 and
    secondPool===3, a single 3-person race was producing
    only 1 finalist instead of 2.
    Fix: racer with most wins receives a bye to the Final,
    the other 2 race for the second Final spot.
  - Verified with 1000 simulations across 5–21 racers.
    All finals correctly assembled as 1+2=3.

ADDED
  - Season points accumulation now aggregates by racer name
    (normalised) instead of temporary race-night ID.
    Racers now correctly accumulate points across events.
  - Export results — three formats from podium screen
    and season standings screen:
    · 💾 HTML — self-contained webpage, good for emailing.
    · 📊 CSV — spreadsheet, opens in Excel.
    · 🖨 Print/PDF — print-ready page with Print button.
  - Junior toggle now shows on all classes (not just EVO).
    Junior flag is a person attribute — affects points
    and standings in EVO class only.
  - Manage Roster modal — edit names, toggle Junior/Adult,
    bulk All Junior / All Adult with search filter, delete.
  - Junior toggle in roster sidebar for quick inline editing.
  - Auto-shutdown when browser tab is closed (heartbeat).
  - Fully offline operation — no internet required.
  - Mac launcher (Start Race Manager.command).
  - Fonts switched to system fonts (Segoe UI / Arial Narrow)
    — no internet required for font loading.
  - CHANGELOG.txt added (this file).
