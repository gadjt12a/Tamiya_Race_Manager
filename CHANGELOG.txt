ADDED
  - Season Roster management — racers can now be marked
    Active or Inactive for a season without being deleted
    from the database.
  - New Season flow: after creating a new season, a
    "Season Roster Setup" modal opens automatically (if
    there are existing racers). Racers who competed in the
    previous season are pre-ticked; others are unticked.
    Untick anyone not returning. The modal is skipped if
    there are no racers in the database yet.
  - "👥 Season Racers" button added to the home screen
    season hero bar. Opens the same roster modal mid-season
    so a returning racer can be re-activated, or a racer
    sitting out can be deactivated, at any point.
  - Inactive racers are hidden from the race setup screen
    roster panel. They still exist in the database and their
    historical points are preserved.
  - "All Active" / "All Inactive" bulk buttons in the
    roster modal for quick selection.

CHANGED
  - Race results are now saved automatically the moment the
    podium screen appears. No one needs to click a save button.
  - "Save Results & Return Home" button renamed to
    "Return Home". Updates to "✓ Saved — Return Home" once
    the save completes.
  - If results are re-saved (e.g. after editing the final race
    result), the existing event entry is updated in place
    rather than creating a duplicate.
  - If auto-save fails, a toast error is shown and the
    coordinator can still return home (data will be lost in
    that case — auto-save failure is a server error).
  - Crash recovery: if the app crashed after the final race
    but before the coordinator had returned home, resuming
    now auto-saves immediately when the podium re-appears.

  - Special events and test races are unaffected; they

FIXED
  - EVO Junior standings were awarding overall-position points
    instead of junior-rank points. A junior finishing 5th overall
    but 1st among juniors now correctly earns 10 pts in the
    Junior table. Their EVO overall points (6 pts for 5th) are
    unchanged — both tables are independent.

ADDED
  - Crash recovery: active race state is checkpointed to
    DB.activeRace after every confirmed race result. If the app
    or server closes unexpectedly mid-race, restarting shows a
    "Race In Progress — Resume?" modal with the class name,
    racer count, and races completed. Resume restores the bracket
    exactly where it left off. Discard clears the checkpoint.
    Test-mode races are excluded from checkpointing.
  - Atomic file writes: server now writes to racedata.json.tmp
    then renames atomically. The data file can never be left
    half-written or corrupt if the process is killed mid-save.
  - stress-test.py: developer tool that simulates 30 race nights
    (Box + EVO + Pro each night, 8–14 racers per class, 3–5
    juniors in EVO) and validates data integrity. Run with
    "python stress-test.py [runs]". Passed 270 events with 0
    errors across 3 runs.

    secondPool===3, a single 3-person race was producing
    only 1 finalist instead of 2.

    the other 2 race for the second Final spot.

    All finals correctly assembled as 1+2=3.

    · 📊 CSV — spreadsheet, opens in Excel.
    · 🖨 Print/PDF — print-ready page with Print button.
  - Junior toggle now shows on all classes (not just EVO).

  - Manage Roster modal — edit names, toggle Junior/Adult,
